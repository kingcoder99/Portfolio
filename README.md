# Karan Magham — Portfolio

A modern, responsive personal portfolio website showcasing my skills, projects, and experience as a **Full Stack Web Developer**.

Built with modern web technologies, smooth animations, and a clean, interactive UI.

## 🚀 Tech Stack

* **Next.js**
* **TypeScript**
* **React.js**
* **Tailwind CSS**
* **Framer Motion**
* **Lucide React**

## ✨ Features

* Modern responsive design
* Animated hero section
* About me section
* Interactive skills showcase
* Featured projects
* Project details and technology tags
* Contact section
* Smooth scrolling and page transitions
* Dark futuristic UI
* Mobile-friendly layout

## 🛠️ Getting Started

Clone the repository:

```bash
git clone https://github.com/KaranMagham/karan-magham-portfolio.git
```

Navigate to the project:

```bash
cd karan-magham-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
